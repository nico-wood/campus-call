# Campus Call — 2-minute demo video script (Challenge 02: Startup Launch Award)

Target runtime **1:50** (the 2:00 limit is a hard disqualifier). ~255 spoken words. Loom with camera bubble on; drive the live site at campus-call.vercel.app in a clean browser window (no bookmarks bar, no other tabs, normal zoom). Log into the demo account **before** recording. Never show the admin/resolve page or any email addresses.

Judges' checklist this script hits in order: the problem → the product → who would pay → how we tested demand → what we learned → proof of potential.

## Recording notes

- **Rehearse the click path once with the mic off.** The clicks are the pacing: when a sentence ends, the next thing should already be on screen.
- One take per section is fine — Loom lets you trim; keep final under 1:55 for safety.
- The leaderboard shows first names + initials only — that's fine; never show the enrollment admin, the resolve flow, or a browser profile with your email visible.
- Banned vocabulary applies on mic: forecasts, tickets, credits, prizes — never bet/wager/odds/payout, and don't say "gambling" in this video (no time to knock the frame down; don't raise it).
- If the live counts have grown by recording time, **say the bigger number** — re-pull from the board first.
- Upload to Loom, set link access to "anyone with the link" and test it in an incognito window (must play without login), then submit on the form before 12:00 PM.
