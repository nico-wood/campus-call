## Gradient renderer

`src/app/gradient-backdrop.tsx` uses a 25×15 design grid of square cells, centered/cropped to cover narrow viewports. It uses a 4×4 Bayer matrix, 76% ordered dithering, 62° diagonal, 7% cell gap, scale 68, softness 26, wave 12, distortion 28, count 6, spread -20, a fade-40 ramp envelope, grain 100, vignette 100, and zero blur. The seeded grain (233428675) and cell geometry are cached. Pixels use the existing black, green, ivory, and gold CSS tokens, at the supplied sorted stop locations 0%, 24%, 61%, and 67%.

The requestAnimationFrame loop uses elapsed seconds with `ph = t * 0.71`, `amt = 0.60`, `dir = 1`, `spin = ph * dir`, and `shift = sin(spin * 0.9) * 0.5 * amt`. The modulation is exactly zero at startup and is a sine sweep, not a wrapping scroll. Animated clock/angle/center/stop values are not rounded. Static grain quantization and integer canvas backing dimensions are unrelated to motion. Only relevant pixel-mode controls are used; arch controls from the supplied multi-mode preset do not apply.

The renderer pauses in hidden tabs, resumes without a clock jump, and paints a still t=0 frame when reduced motion is requested. A live preference change stops animation. Resize recalculates square-cell cover geometry; backing DPR is capped at 1.5. Cleanup cancels RAF and removes listeners. No React state updates or repeated readiness-attribute writes occur per frame. The previous CSS/SVG treatment remains a no-JavaScript/unavailable-canvas fallback and is hidden once canvas has painted.

The backdrop is decorative and ignores pointer input. Cards, navigation, forms, tickets, and footer remain opaque. Detail data gets further background attenuation. The small example-count label now has a dark surface and stronger text to remain readable through the moving light band.
