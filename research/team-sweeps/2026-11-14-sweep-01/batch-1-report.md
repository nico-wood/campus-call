## Coverage and limitations

- First sweep covers 30 roster team labels and all 84 associated member rows; check-in labels are not verified final entrants.
- Every member received exact-name school/GitHub and site:github.com web queries. Every team received a name+Cal Poly+hackathon+GitHub query. Many searches returned unrelated results and were rejected.
- Additional GitHub fullname/API searches and repository reads were performed for promising leads. GitHub search rate limits interrupted some optional deeper searches; those are not negative findings.
- Search-indexed profile claims are marked likely where direct identity confirmation is absent. LinkedIn opens and some GitHub web opens failed; repository API reads succeeded for selected leads.
- No participant emails retained in these reports. No Discord scraping, contact requests, private-profile access, external code execution, or live form interactions.
- No numeric win probabilities, rubric grades or assumptions based on major/year. Unknown is not zero and lack of discoverability is not evidence of weak execution.
- Prior competitions and class projects remain background only. Public deployment URLs from old projects are not current team live links.

Search strategy: exact participant name + GitHub + university; exact participant name scoped to github.com; exact team name + Cal Poly + hackathon + GitHub. Supplemental GitHub API fullname searches and recent-public-repository reads were used for promising leads. Namesakes, unrelated datasets, older competitions and class projects were not promoted to current entries.
